# React Textura List Project

A modern React application featuring a collapsible Textura list component with smooth animations and responsive design.

## Features

- ⚛️ React 18 with JSX
- 📦 Vite for fast development and building
- 🎨 Textura list component with expandable items
- 📱 Fully responsive design
- ✨ Smooth animations and transitions

## Getting Started

```bash
npm install
npm run dev
```
